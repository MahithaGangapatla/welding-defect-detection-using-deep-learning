# Deep Learning Based Automated Welding Defect Detection Using Computer Vision

## Internship Details
- Organization: Indian Institute of Technology Tirupati (IIT Tirupati)
- Role: Research Intern
- Duration: Summer Internship 2026

## Project Overview
This project focuses on automatically detecting welding defects from X-ray and weld images using deep learning and computer vision techniques. The system identifies defects such as cracks, porosity, slag inclusion, lack of fusion, and undercut.

## Objectives
- Detect welding defects automatically
- Improve inspection accuracy
- Reduce manual inspection time
- Support quality control in manufacturing

## Defects Detected
- Crack
- Porosity
- Slag Inclusion
- Lack of Fusion
- Undercut

## Techniques Used
- Image preprocessing
- Data augmentation
- Convolutional Neural Networks (CNN)
- YOLO-based object detection

## Technologies
- Python
- OpenCV
- TensorFlow / PyTorch
- NumPy
- Matplotlib
